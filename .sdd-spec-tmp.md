# Specs: frontend-maquetacion-stitch
UI-only Stitch→React. Brand Tequendama. DESIGN.md SoT. No API/auth.

---

# ui-foundation

## Requirements

### Requirement: DESIGN.md tokens
MUST map colors/type/spacing/radii from DESIGN.md (cards 1rem; buttons/inputs 0.75rem; chips pill). Amber `#FFBF00` for CTAs/alerts.

#### Scenario: Tokens apply
- GIVEN app load
- WHEN styles resolve
- THEN Mist/Forest palette and DESIGN radii apply

### Requirement: Fonts and icons
MUST use Manrope (display/headline/body), Sora (labels), Material Symbols.

#### Scenario: Fonts/icons visible
- GIVEN any screen
- WHEN rendered
- THEN Manrope/Sora and Material Symbols appear

### Requirement: Brand Tequendama
MUST show Tequendama only. MUST NOT show AseguraIA or Sales AI.

#### Scenario: No legacy brand
- GIVEN any of 4 routes
- WHEN copy inspected
- THEN only Tequendama branding appears

### Requirement: Local assets
MUST NOT load `lh3.googleusercontent`. Assets MUST be local.

#### Scenario: No lh3 URLs
- GIVEN running app
- WHEN images load
- THEN sources are local paths

### Requirement: Layouts and primitives
MUST provide Marketing, Call, AppShell layouts and Button/Card/Chip/Icon.

#### Scenario: Layout shells
- GIVEN a routed page
- WHEN rendered
- THEN matching layout mounts without Vite scaffold

# screen-landing

## Requirements

### Requirement: Route `/`
MUST render landing at `/`.

#### Scenario: Open root
- GIVEN app running
- WHEN navigate `/`
- THEN landing renders without errors

### Requirement: Landing sections
MUST include fixed nav, hero, trust, Vida/Auto/Salud cards, insight, footer.

#### Scenario: Sections present
- GIVEN `/`
- WHEN user scrolls
- THEN nav, hero, trust, ramos, insight, footer present

### Requirement: CTA to call
Live-call CTA MUST Link to `/llamada`.

#### Scenario: CTA navigates
- GIVEN `/`
- WHEN activate live-call CTA
- THEN location is `/llamada`

# screen-live-call

## Requirements

### Requirement: Route `/llamada`
MUST show header/timer, visualizer, transcript, quote aside, bottom controls.

#### Scenario: Open call
- GIVEN app running
- WHEN navigate `/llamada`
- THEN all call chrome regions render

### Requirement: UI-only controls
Mute/end/send MUST be chrome-only; MUST NOT call telephony/APIs.

#### Scenario: Mute local
- GIVEN `/llamada`
- WHEN click mute
- THEN visual toggle MAY occur AND no network call

### Requirement: Visualizer stub
MUST show presentational stub (CSS/canvas/Three OK). Full shader MAY defer.

#### Scenario: Visualizer occupied
- GIVEN `/llamada`
- WHEN rendered
- THEN visualizer region is non-empty

### Requirement: Mock transcript/quote
MUST show static mock transcript and quote.

#### Scenario: Mock panels
- GIVEN `/llamada`
- WHEN panels render
- THEN ≥1 transcript message and quote visible

# screen-agent-panel

## Requirements

### Requirement: Route `/vendedor`
MUST show sidebar, header, tabs, leads table, drawer with mock leads.

#### Scenario: Open agent
- GIVEN app running
- WHEN navigate `/vendedor`
- THEN sidebar, tabs, table with mock leads render

### Requirement: Filter tabs
Tabs Todos/En Seguimiento/Cerrados MUST switch active chrome; MAY filter mock data.

#### Scenario: Switch tab
- GIVEN `/vendedor`
- WHEN select En Seguimiento
- THEN tab active AND table shows that mock subset

### Requirement: Drawer open/close
Lead select MUST open drawer with mock insights/transcript. MUST close via control/Escape.

#### Scenario: Open drawer
- GIVEN `/vendedor`
- WHEN select a lead row
- THEN drawer opens with that lead mock detail

#### Scenario: Esc closes drawer
- GIVEN open drawer
- WHEN press Escape
- THEN drawer closes

# screen-manager-dashboard

## Requirements

### Requirement: Route `/gerente`
MUST show top nav, sidebar, 4 KPIs, agents table, alerts, leaderboard, prediction.

#### Scenario: Open manager
- GIVEN app running
- WHEN navigate `/gerente`
- THEN KPI, agents, alerts/leaderboard, prediction render

### Requirement: Mock metrics
KPIs/agents/alerts/leaderboard MUST be static mock. Counters MAY be static.

#### Scenario: Mock KPIs
- GIVEN `/gerente`
- WHEN rendered
- THEN 4 KPI cards and non-empty agent/leaderboard lists show

### Requirement: Cross-route nav
Shell links among `/`, `/llamada`, `/vendedor`, `/gerente` MUST navigate without auth.

#### Scenario: Nav to agent
- GIVEN `/gerente`
- WHEN follow nav to `/vendedor`
- THEN agent panel renders
